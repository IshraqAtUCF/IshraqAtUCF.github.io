Research Experience

Graduate Research Assistant — University of Central Florida, Orlando, FL (Jan 2024–Present)
Hardware Security and Trustworthy Computing Lab, advised by Dr. Sazadur Rahman

  • AI-assisted hardware security verification and vulnerability reasoning. Developed methods connecting standardized vulnerability knowledge, hardware structural information, AI-assisted reasoning, and formal/property-based verification to automate security analysis of semiconductor designs. This research includes ATLAS and continuing work on Aegis and related security-verification frameworks.
  • ATLAS — threat-to-assertion learning for SoC security (DAC 2026). Developed an AI-assisted framework that identifies hardware assets, maps relevant weaknesses from standardized sources such as CWE, constructs structured threat models, and generates assertion-based security properties and formal-verification scripts. Across three HACK@DAC benchmark designs, ATLAS identified 39 of 48 evaluated weaknesses and generated correct security properties for 33 of the 39 identified cases.
  • Security knowledge across synthesis and implementation. Investigating how security assets, assumptions, countermeasures, verification obligations, and policies can be preserved and checked across synthesis transformations. Secure-SDC focuses on retaining security knowledge and verification obligations across synthesis.
  • Security assurance for open-source semiconductor design flows. Since Sept 2026, contributing to SecureOpenROAD research on security assurance across synthesis and physical implementation. Identified security-critical metrics for semiconductor design flows that helped shape the methodology in the submitted research proposal.
  • Security of heterogeneous and chiplet-based systems (HOST 2026, GOMACTech 2026, PAINE 2025, GLSVLSI 2025). Developed authentication and trust architectures for System-in-Package and chiplet-based systems, including SAFE-SiP, AuthenTree, InterPUF, and RoutePUF. The work combines multi-party computation, physically unclonable functions, distributed trust, and interposer-resident security mechanisms.
  • Secure test and verification for heterogeneous systems. Investigating security-aware test and verification for chiplet-based systems, including protection of authentication, test, and inter-chiplet information in multi-vendor environments.
  • Hardware IP protection and reconfigurable security (ICCD 2025). Developed ECOLogic, an eFPGA-augmented SoC methodology supporting post-fabrication adaptability, logic obfuscation, and hardware IP protection while maintaining practical implementation characteristics.
  • Machine learning for semiconductor physical design (MLCAD 2025). Developed BeyondPPA, a human-inspired reinforcement-learning methodology for macro placement that incorporates practical physical-design considerations and post-route reliability objectives beyond conventional PPA optimization. Selected as a Best Paper Award Nominee at MLCAD 2025.
